GROUP 8 MINI WEBSITE PROJECT
=============================

CONTENTS
--------
index.html       Home page
gallery.html     Image gallery in a responsive grid
blog.html        Two styled blog posts with links
contact.html     Interactive contact form with browser validation
reflection.html  One-page reflection on modern HTML5 features
style.css        Shared external stylesheet
script.js        Mobile menu, copyright year and form interaction

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open the Group-8-Mini-Website folder.
3. Double-click index.html to open the site in a web browser.
4. Use the navigation bar to visit all pages.

NOTES
-----
- The gallery and hero use remote Unsplash images, so an internet connection is needed to display them.
- Google Fonts are also loaded online. System fallback fonts are included.
- The contact form demonstrates required-field and email validation and displays a success message. It does NOT email, save or transmit submissions. A real submission feature requires a backend or a form service.
- Replace the sample social media links with your group's actual profiles if available.
- Update the blog content, group details and contact information to match your class requirements.

PUBLISHING WITH GITHUB PAGES
----------------------------
1. Sign in to GitHub and create a new public repository, for example: group-8-mini-website.
2. Upload all files in this folder to the repository's root (not the ZIP file).
3. Open the repository's Settings, then Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and the root folder, then save.
6. Wait for GitHub Pages to publish. Copy the website address shown in the Pages section and share it with your classmates.

PUBLISHING WITH NETLIFY
-----------------------
1. Sign in to Netlify.
2. Choose Add new site / Deploy manually (wording may vary).
3. Drag the extracted website folder into the deployment area.
4. Wait for deployment and copy the public site link.
